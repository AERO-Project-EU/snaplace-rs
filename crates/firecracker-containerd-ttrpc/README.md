# firecracker-containerd-ttrpc

In this crate:

- We have authored only:
  * [`Cargo.toml`](Cargo.toml),
  * [`build.rs`](build.rs),
  * [`src/lib.rs`](src/lib.rs), and
  * [`src/fc_ctrd/mod.rs`](src/fc_ctrd/mod.rs).

- All other `.rs` source files in [`src/fc_ctrd/`](src/fc_ctrd) are
  automatically (programmatically) generated by the
  [ttrpc-rust compiler](https://github.com/containerd/ttrpc-rust/tree/master/compiler)
  through our [`build.rs`](build.rs).

- We have included "as-is" all files in [`proto/google/`](proto/google) from the
  [protobuf repo](https://github.com/protocolbuffers/protobuf/).

- We have included "as-is" all proto definitions found in
  [our fork of firecracker-containerd](https://github.com/ckatsak/fc-ctrd/).
  Note that these are modified compared to the original definitions found in
  [firecracker-containerd](https://github.com/firecracker-microvm/firecracker-containerd/).
